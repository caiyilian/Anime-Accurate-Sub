# Anime Accurate Sub - 项目需求文档

## 项目概述

输入一个视频文件，自动嵌入精准的中文字幕。主要用于没有中文字幕的日语动漫视频。

## 核心痛点

- 日语动漫缺乏中文字幕，手动找字幕很麻烦
- 浏览器自动字幕翻译工具（如 YouTube 自动翻译）错误率很高，翻译不准确
- 现有方案对动漫领域的专有名词、角色名、语气词等处理较差

## 核心需求

### 1. 语音识别 (ASR)
- 从视频中提取日语语音
- 对日语动漫语音有较高的识别准确率
- 支持说话人区分（角色分离）

### 2. 翻译 (Translation)
- **日语 → 中文** 的准确翻译
- 对动漫场景、口语化表达、角色语气有良好表现
- 保持角色名称翻译的一致性
- 支持专有名词（招式、地名、术语等）的准确翻译

### 3. 字幕嵌入 (Subtitle Embedding)
- 将翻译后的中文字幕嵌入视频文件
- 支持 ASS/SRT 等常见字幕格式
- 字幕样式美观（字体、大小、位置、描边等）
- 支持双语字幕（日语原文 + 中文翻译）可选

### 4. 本地运行 (Local Execution)
- **必须支持通过 Ollama 运行本地模型**，不需要依赖云端 API
- 也可选支持调用云端 API（如 OpenAI、Claude 等）作为备选
- 敏感数据不上传外部服务

## 技术栈方向（待定）

| 模块 | 候选方案 |
|------|---------|
| 语音识别 (ASR) | Whisper / Faster-Whisper / SenseVoice / 本地模型 |
| 说话人分离 (Diarization) | pyannote.audio / 其他方案 |
| 翻译 (Translation) | Ollama 本地 LLM（如 Llama、Qwen 等）/ 云端 API 备选 |
| 字幕封装 | FFmpeg / ass 库 |
| 语言 | Python（优先） |
| 其他工具 | yt-dlp（视频下载，可选） |

## 工作流程

```
输入视频文件
    ↓
提取音频轨道
    ↓
语音识别 (ASR) → 日语原文 + 时间戳
    ↓
（可选）说话人分离
    ↓
日语文本分段
    ↓
翻译为中文（Ollama 本地模型 / API）
    ↓
生成字幕文件 (SRT/ASS)
    ↓
嵌入视频 → 输出带字幕的视频
```

## 未来拓展方向

- 批量处理（多集动漫自动处理）
- 支持更多语言对（如英语→中文、日语→英语）
- Web UI / GUI 界面
- 字幕样式模板自定义
- 翻译结果人工校对与修正功能

## 非功能性需求

- 支持 GPU 加速（CUDA）
- 良好的断点续传能力（避免长视频处理中途失败全部重来）
- 清晰的日志输出，方便排查问题
