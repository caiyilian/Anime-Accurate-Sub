## 各方案详细评估

### 方案 A：VAD + ECAPA-TDNN + 聚类（S6.1）

**状态：已成功运行**

| 维度 | 评估 |
|:----|:------|
| 说话人区分 | ✅ 能区分不同角色（multi_01/multi_03 检出 4 个说话人） |
| 实时性 | ✅ RTF ≈ 0.048（20x 实时） |
| 峰值 VRAM | ✅ ~2.5 GB（ECAPA-TDNN + Anime Whisper 同时加载） |
| VAD 鲁棒性 | ❌ 能量阈值不通用，安静场景漏检 |
| 部署难度 | ✅ 无 gated 模型，pip install 即可 |

**结论**：核心方案可行，但 VAD 需要改进。

### 方案 B：DiariZen

**GitHub**：https://github.com/BUTSpeechFIT/DiariZen（492 stars）

**尝试过程**：
1. ✅ `pip install diarizen` — 从源码安装成功（Python 3.13 兼容）
2. ✅ 模型下载成功：`BUT-FIT/diarizen-wavlm-large-s80-md`（265 MB）
3. ✅ 嵌入模型下载成功：`pyannote/wespeaker-voxceleb-resnet34-LM`（25 MB）
4. ❌ **初始化失败**：`TypeError: SpeakerDiarization.__init__() got an unexpected keyword argument 'config'`
   - 原因：DiariZen 基于 `pyannote.audio.pipelines.SpeakerDiarization` 旧版 API 开发
   - 当前环境安装的 pyannote-audio 4.0.7 与 DiariZen 不兼容
   - DiariZen 官方推荐使用 Python 3.10 + PyTorch 2.1.1

**许可证**：模型权重为 CC BY-NC 4.0（非商业），项目代码为 MIT。

**结论**：在 Python 3.13 + PyTorch 2.11.0 环境下不可用。即使降级环境，仍需解决 pyannote 版本兼容问题。

### 方案 C：NVIDIA Sortformer（NeMo）

**文档**：https://docs.nvidia.com/nemo-framework/user-guide/latest/nemotoolkit/asr/speaker_diarization/intro.html

**HF 模型**：`nvidia/diar_sortformer_4spk-v1`

**尝试过程**：
1. ❌ `pip install nemo_toolkit[asr]` — 构建失败
   - 依赖 `editdistance==0.8.1` 需要 C++ 编译器（`cl.exe`）编译 C 扩展
   - Windows 环境缺少构建工具链
   - NeMo 的依赖树庞大（177 个包），复杂度过高

**结论**：Windows 下部署 NeMo 需要完整的 MSVC 工具链，环境依赖复杂。不支持快速部署。

### 方案 D：Kotoba-Whisper v2.2 内置 diarization

**S6.1 已评估**：不可用。

- 内部依赖 `pyannote/speaker-diarization-3.1`（gated 模型）
- 用户需手动接受 HF 许可证
- 即使接受，`diarizers-community/speaker-segmentation-fine-tuned-callhome-jpn` 只有 TensorFlow 权重

### 方案 E：pyannote/speaker-diarization-3.1

**S6.1 已评估**：不可用。

- Gated 模型，需要用户手动接受许可证
- 作为可选方案保留（未来如果用户接受许可证可直接启用）

## 最终方案决策

### 选择：方案 A（VAD + ECAPA-TDNN + 聚类），并改进 VAD

```
输入 WAV
  -> [改进] Silero-VAD 语音活动检测
  -> ECAPA-TDNN 说话人嵌入提取
  -> AgglomerativeClustering 聚类
  -> Anime Whisper ASR
  -> ASR 段与 VAD 段最大重叠说话人分配
  -> 输出 [speaker_id, start, end] 列表
```

### 改进计划

| 改进项 | 当前状态 | 目标 |
|:-------|:--------|:-----|
| VAD 算法 | 能量阈值（不鲁棒） | 替换为 Silero-VAD |
| 聚类参数 | 固定 4 簇 | 自适应簇数估计 |
| 说话人分配 | 最大重叠匹配 | 更精确的边界对齐 |
| 接口定义 | 无 | `diarize(audio: WAV) -> List[SpeakerSegment]` |
