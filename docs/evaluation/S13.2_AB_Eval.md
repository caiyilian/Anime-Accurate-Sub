## 结论

### 使用方式

```bash
# 对比两个 ASR 模型的 CER
python scripts/ab_eval.py \
  --ref gold_standard.json \
  --a anime_whisper_output.json \
  --b large_v3_output.json \
  --a-name "Anime Whisper" \
  --b-name "large-v3"

# 带术语表对比
python scripts/ab_eval.py \
  --ref gold_standard.json \
  --a model_a.json --b model_b.json \
  --glossary data/glossary/k-on_glossary.json

# 运行测试
python scripts/ab_eval.py --evaluate
```

### 注意

- 输入 JSON 支持 `text`/`transcription`/`ja`/`zh` 字段
- CER 依赖 jiwer 库；未安装时使用内置 Levenshtein 回退
- 术语命中率需要提供 glossary JSON
