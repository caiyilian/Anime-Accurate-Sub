### 3.2 运行参数

```bash
cli.py --task vtv \
    --name "k-on_epXX.mp4" \
    --source_language_code ja \
    --target_language_code zh-cn \
    --recogn_type 0 \       # faster-whisper（本地）
    --model_name large-v3 \
    --cuda \                # GPU 加速
    --translate_type 9 \    # 本地 AI/本地模型（指向 Sensenova API）
    --subtitle_type 0 \     # 仅输出字幕，不嵌入视频
    --verbose
```

## 五、ASR 质量对比

### tiny vs large-v3 识别结果

| 场景 | tiny (75MB) | large-v3 (3GB) |
|------|:----------:|:--------------:|
| 第一句问候 | こんにちは | 姉ちゃん、見学 ✅ |
| 角色称呼 | よろしくお願いします | 楽しみだね、唯ちゃん ✅ |
| 长句识别 | でも、私のプロフィ...（截断）| でも、私のプロフィールに書いてある ✅ |
| 对话内容 | 目指すボールを頭で！（错误）| 全部諦めて帰りたい ✅ |

**结论**: large-v3 在日语动漫场景下识别准确度显著优于 tiny，是可用方案。

## 七、优缺点

### 优点

| 方面 | 评价 |
|------|------|
| **ASR 质量** | faster-whisper large-v3 + GPU 加速，识别准确度高 |
| **翻译质量** | 通过 Sensenova LLM 翻译，自然度好 |
| **全流程自动化** | 一键完成 视频→音频→ASR→翻译→字幕 全流程 |
| **批量处理** | CLI 支持批量，14 集连续运行无问题 |
| **可扩展性** | 支持 25+ ASR 渠道、20+ 翻译渠道、30+ TTS 渠道 |
| **CLI 完善** | 参数丰富，适合脚本化运行 |
| **社区活跃** | 18K Star，持续更新，文档完善 |

### 缺点

| 方面 | 评价 |
|------|------|
| **无 OP/ED 检测** | 片头片尾的歌曲和广告也会被 ASR 识别，产生无效字幕 |
| **无说话人分离** | 所有字幕同一风格，无法区分角色 |
| **无术语表** | 角色名/专有名词翻译不可控，依赖 LLM 上下文 |
| **无翻译记忆** | 相同台词每集都会重新翻译，可能不一致 |
| **输出格式** | `--subtitle_type 0` 仅输出 SRT，不嵌入视频 |
| **模型体积** | large-v3 ~3GB，首次下载耗时较长 |
| **网络依赖** | 翻译依赖 Sensenova API（虽国内可直连） |

## 八、与项目需求的匹配度

### 8.1 可直接复用的模块

| 模块 | 说明 |
|------|------|
| **faster-whisper ASR** | 核心 ASR 方案，可直接复用 |
| **CLI 调用框架** | 参数解析、任务队列、进度反馈 |
| **翻译调度器** | 支持多渠道翻译，可扩展 |
| **FFmpeg 集成** | 音频提取、视频处理 |
| **pysubs2 SRT 处理** | 字幕读写 |

### 8.2 需要自行开发的功能

| 功能 | 优先级 | 说明 |
|------|:-----:|------|
| OP/ED 检测 | 高 | 跳过片头片尾，减少无效 ASR 和翻译 |
| 说话人分离 | 中 | 字幕标注角色，角色专属颜色 |
| 术语表 | 高 | 控制角色名/招式名等专有名词翻译 |
| 翻译记忆 | 中 | 跨集同一台词复用相同翻译 |
| 多 Agent 审查 | 低 | 后续可扩展的审查流水线 |

## 九、结论

| 结论 | 说明 |
|------|------|
| **作为底座可行性** | ⚠️ 部分可行 |
| **推荐复用方式** | 核心 ASR + 翻译调度 + CLI 框架可复用，缺失功能自行补充 |

pyVideoTrans 是一个成熟的全流程工具，在 ASR 和翻译调度方面表现优秀。但缺少动漫字幕所需的 OP/ED 检测、说话人分离、术语表等关键功能。

**建议**: 完成 S1.2（VideoLingo）和 S1.3（WhisperJAV）评估后，综合对比再做底座选型决策。
