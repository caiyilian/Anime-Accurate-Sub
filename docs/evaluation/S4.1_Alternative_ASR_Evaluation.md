# S4.1 ASR 备选评估 + AED 测试报告

> 日期: 2026-07-12
> 测试集: 200 条日语语音片段 (~15 min)
> 环境: Python 3.13 + torch 2.11.0+cu128, RTX 3060 12GB

## 三模型对比

| 模型 | Avg CER | Med CER | RTF | 大小 | 特点 |
|------|:-------:|:-------:|:---:|:----:|------|
| **Anime Whisper (主力)** | **0.1299** | **0.0607** | **0.102** | 1.5GB | kotoba-whisper v2.0 蒸馏版, 5,300h Galgame 微调 |
| **efwkjn/whisper-ja-anime-v0.3** | 0.2778 | 0.1056 | **0.089** | ~1.5GB | large-v3-turbo 微调, 日语 tokenizer, 速度更快 |
| SenseVoice Small | 0.3307 | 0.2500 | **0.017** | 936MB | 非 Whisper 架构, 多语言 + AED, 速度极快 |

## SenseVoice Small 详细分析

### ASR 精度

| 指标 | 值 |
|------|:---:|
| **平均 CER** | **0.3307 (33.07%)** |
| **中位数 CER** | **0.2500 (25.00%)** |
| P90 CER | 0.8148 |
| RTF | **0.0172** (~60x 实时) |
| 模型加载时间 | 4.3s |

SenseVoice 的 ASR 精度明显低于 Anime Whisper（CER 33% vs 13%），但速度极快（RTF 0.017 vs 0.102，约 6 倍速度优势）。

### AED (音频事件检测)

SenseVoice 内置 AED 能力，每条 ASR 输出自动附带事件标签。测试 200 条样本：

| 检测标签 | 含义 | 检测结果 |
|----------|------|:--------:|
| `<|Speech|>` | 语音 | 多数样本 |
| `<|Cry|>` | 哭声 | sample_0003 等 |
| `<|EMO_UNKNOWN|>` | 未知情感 | 全部样本（情感分类未启用） |
| `<|ja|>` | 日语 | 自动语言检测 |
| `<|withitn|>` | 反文本归一化 | 全部样本 |

AED 可用于 OP/ED 检测：如果连续检测到 `<|Music|>` 或 `<|BGM|>` 标签，则可判定为 OP/ED 段落。当前测试集主要是语音片段，未触发 Music/BGM 标签。

## 结论

### ASR 选型建议

**Anime Whisper 仍然是主力 ASR 模型的最优选择。** SenseVoice ASR 精度不足（CER 33%），不适合作为主要 ASR 引擎。但其极快的速度（RTF 0.017）使其适合作为：

1. **快速通道**：对精度要求不高的场景（如预览、快速索引）
2. **AED 分类器**：用于 OP/ED 检测（检测 Music/BGM 标签）
3. **语音活动检测（VAD）**：替代 Silero VAD

### efwkjn/whisper-ja-anime-v0.3

| 指标 | 值 |
|------|:---:|
| **平均 CER** | **0.2778 (27.78%)** |
| **中位数 CER** | **0.1056 (10.56%)** |
| P90 CER | 1.0000 |
| RTF | **0.089** (比 Anime Whisper 快 15%) |
| 模型加载时间 | 2.5s |

efwkjn 基于 large-v3-turbo 微调（4 层 decoder），速度比 Anime Whisper（2 层 distilled）还快 15%，但精度反而不如。中位数 CER 0.1056 vs 0.0607，说明在大部分普通片段上 efwkjn 的识别精度不如 Anime Whisper。

### efwkjn 模型

`efwkjn/whisper-ja-anime-v0.3` 基于 large-v3-turbo 微调（4 decoder layers），精度介于 Anime Whisper (2 layers distilled) 和 large-v3 之间。实测结果：平均 CER 0.2778，中位数 CER 0.1056，RTF 0.089。**Anime Whisper 仍然是最优选择。**

### 对管道的建议

使用 **SenseVoice AED** 作为 OP/ED 检测层（替换/补充 AnimeTranslator 的 85-95s 音乐检测），ASR 仍使用 **Anime Whisper**。
