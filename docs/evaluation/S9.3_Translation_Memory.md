# S9.3 翻译记忆库评估

> 日期：2026-07-13
> 目标：实现翻译记忆库，通过 JSONL 持久化缓存翻译结果，避免重复调用 LLM

---

## 实现方案

### 模块 `scripts/translation_memory.py`

| 功能 | 说明 |
|:----|:------|
| 精确匹配缓存 | 日语原文 → 中文翻译的直接映射 |
| JSONL 持久化 | 每行一个 JSON 对象，跨会话可用 |
| 自动保存 | 新翻译立即写入磁盘（可选关闭） |
| 命中率统计 | 记录 hit/miss/store 次数 |
| 模型标识 | 每条记录包含模型名和时间戳 |

### 数据格式

```jsonl
{"ja": "おはよう", "zh": "早上好", "model": "translategemma:4b", "timestamp": "2026-07-13T13:30:00"}
{"ja": "今日も元気だね", "zh": "今天也很精神呢", "model": "translategemma:4b", "timestamp": "2026-07-13T13:30:01"}
```

---

## 评估结果

### 测试结果

| 测试 | 结果 |
|:----|:------|
| 第一次调用 | Miss → 调用模型翻译 → 存入 TM |
| 第二次调用相同句子 | **Hit → 直接返回缓存，不调用模型** |
| 跨会话加载 | 从 JSONL 文件加载成功，缓存有效 |

### 性能影响

| 操作 | 耗时 |
|:----|:----:|
| TM 查找（内存 dict） | < 0.001ms |
| TM 写入（JSONL） | < 1ms |
| 加载 1000 条（JSONL） | < 10ms |
| 相比调用 LLM（~0.5s） | **节省 99.9%+ 时间** |

---

## 结论

### 翻译记忆库有效，强烈建议启用

| 场景 | 效果 |
|:----|:------|
| 相同台词重复出现（如"早上好"） | 第二次直接返回，零延迟 |
| 同一系列多集翻译 | 常见对白自动命中 TM |
| 断句的重复片段 | 精确匹配直接命中 |

### 使用方式

```python
from scripts.translation_memory import TranslationMemory
from scripts.translate import translate

tm = TranslationMemory("data/translation_memory.jsonl")
result = translate("おはよう", tm=tm)  # 第一次：调用模型
result = translate("おはよう", tm=tm)  # 第二次：返回缓存
```

### 环境变量

```bash
set TM_FILE=data/translation_memory.jsonl
```
