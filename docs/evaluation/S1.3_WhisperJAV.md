## 三、管线架构详解

WhisperJAV 的核心是其**分阶段管线架构**，每个阶段可独立配置和替换。

### 3.1 管线总览

| 管线 | 后端 | 场景检测 | 语音增强 | 语音分段 | 适用场景 |
|------|------|:---------:|:---------:|:---------:|---------|
| **faster** | Faster-Whisper (turbo) | — | — | — | 速度优先，清晰音频 |
| **fast** | OpenAI Whisper | Auditok | — | — | 通用，混合质量 |
| **balanced** | Faster-Whisper | Auditok | 可选 | Silero | **默认**，噪音/对话场景 |
| **fidelity** | OpenAI Whisper | Auditok | 可选 | Silero | 最高精度，较慢 |
| **transformers** | HuggingFace Kotoba | 可选 | 可选 | 可选 | Kotoba 日语模型 |
| **qwen** | Qwen3-ASR | 语义 | 可选 | Silero | Qwen ASR + 强制对齐 |
| **anime** | anime-whisper | 语义 | 可选 | TEN | **动漫/JAV 对话调优** |

### 3.2 管线处理流程

以 `balanced` 模式为例：

```
输入视频
    ↓
[1. 音频提取]  → FFmpeg 提取 16kHz WAV
    ↓
[2. 场景检测]  → Auditok（静音检测）→ 切分为 2 个场景
    ↓
[3. 语音增强]  → 可选（ClearVoice / FFmpeg DSP / BS-RoFormer）
    ↓
[4. VAD 分段]  → Silero VAD → 每个场景精确标注语音区间
    ↓
[5. ASR 转录]  → Faster-Whisper large-v2 → 逐片段转录
    ↓
[6. 后处理]    → 幻觉过滤 / 重复检测 / 日语后处理
    ↓
[7. 输出]      → SRT / VTT 字幕
```

### 3.3 场景检测方法

| 方法 | 原理 | 适用场景 |
|------|------|---------|
| **Auditok** | 基于能量/静音检测 | 通用，速度快 |
| **Silero** | 神经网络 VAD 检测 | 噪音较大的音频 |
| **Semantic** | MFCC 特征聚类 | 需要语义分割时 |

### 3.4 VAD 语音分段

WhisperJAV 支持多种 VAD 后端：

| 后端 | 说明 | 模型大小 |
|------|------|:--------:|
| **Silero** | PyTorch Hub 预训练 VAD，精度高 | ~2MB |
| **TEN** | TEN Framework，用于 ChronosJAV | ~2MB |
| **NEMO** | NVIDIA NeMo VAD | ~0.5GB |
| **Whisper-VAD** | 基于 Whisper small 的 VAD | ~500MB |
| **WhisperSeg** | 基于 Whisper encoder 的 VAD，JAV 优化 | ONNX |

### 3.5 幻觉过滤

WhisperJAV 内置强大的幻觉过滤系统：

- **3927 条短语过滤列表**：从 Gist 自动更新
- **36 条正则表达式**：匹配常见幻觉模式
- **对数概率阈值过滤**：低置信度输出自动丢弃
- **重复检测**：检测并移除重复文本
- **CPS 限制器**：限制每秒字符数，防止爆音

## 五、ASR 质量

### 5.1 ASR 识别结果（faster 模式）

```
Line 1: リツ、クラブ見学?
Line 2: 慶恩部だよ、慶恩部!
Line 3: でも、私、文芸部に入るつもりなんだけど?
Line 4: 入部希望の紙も書いたし
Line 5: ビリ
```

### 5.2 识别质量分析

| 场景 | 原文（正确） | ASR 识别 | 评价 |
|------|:-----------:|:--------:|:----:|
| 角色呼唤 | リツ！ | リツ | ✅ 正确 |
| 社团参观 | クラブ見学行こうぜ！ | クラブ見学? | ⚠️ 部分截断 |
| 部门名称 | 軽音部 | 慶恩部 | ❌ 同音异字错误 |
| 长句 | でも私文芸部に入るつもりなんだけど | でも、私、文芸部に入るつもりなんだけど? | ✅ 正确 |
| 入部申请 | 入部希望の紙も書いたし | 入部希望の紙も書いたし | ✅ 正确 |
| 语气词 | ビリ（じゃあ） | ビリ | ⚠️ 不太准确 |

**结论**: WhisperJAV（large-v2）的 ASR 质量与 pyVideoTrans（large-v3）基本持平，同音字错误（軽音部→慶恩部）是 Whisper 系列的通病。

## 六、优缺点

### 优点

| 方面 | 评价 |
|------|------|
| **管线架构** | 7 种管线 + 可插拔组件，易于扩展 |
| **场景检测** | 支持 Auditok / Silero / 语义三种方法 |
| **VAD 多样化** | 支持 6+ 种 VAD 后端，针对不同场景优化 |
| **幻觉过滤** | 内置 4000+ 条规则，自动移除幻觉 |
| **日语后处理** | 语气词保留、方言识别、Whisper 幻觉清除 |
| **集成模式** | 双管线合并，多种合并策略 |
| **CLI 完善** | 参数丰富，支持批量处理 |
| **GPU 加速** | CUDA 支持良好，显存占用低 |
| **输出格式** | SRT + VTT 双格式 |

### 缺点

| 方面 | 评价 |
|------|------|
| **无说话人分离** | 所有字幕同一风格 |
| **无 OP/ED 检测** | 片头片尾也会被 ASR 识别 |
| **无内置翻译** | 需要额外配置翻译模块（PySubtrans） |
| **GitHub 强依赖** | Silero VAD 通过 torch.hub 从 GitHub 下载 |
| **Anime-Whisper 模型大** | ~4GB，从 HuggingFace 下载 |
| **场景检测简单** | Auditok 基于静音，复杂场景不够精确 |
| **无翻译记忆** | 相同台词每集重新翻译 |

## 八、Sprint 1 结论

### 8.1 完成情况

| 子阶段 | 项目 | 状态 |
|:------|:----|:----:|
| S1.1 | pyVideoTrans 评估 | ✅ 完成 |
| S1.2 | VideoLingo 评估 | ✅ 完成 |
| S1.3 | WhisperJAV 评估 | ✅ 完成 |

### 8.2 Sprint 1 核心发现

1. **ASR 方案**: Anime Whisper (large-v3) 通过 faster-whisper 加载为最佳方案，质量高、速度快
2. **翻译方案**: VideoLingo 的三步翻译（总结→直译→意译）质量显著优于单步翻译
3. **场景/VAD**: WhisperJAV 的 Auditok 场景检测 + Silero VAD 可直接复用
4. **幻觉过滤**: WhisperJAV 的 4000+ 规则过滤系统值得引入
5. **底座**: 建议以 pyVideoTrans 为基础，整合 VideoLingo 的三步翻译和 WhisperJAV 的 VAD/幻觉过滤
