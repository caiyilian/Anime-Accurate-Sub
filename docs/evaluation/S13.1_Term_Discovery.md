# S13.1 专有名词自动发现评估

> 日期：2026-07-13
> 目标：从 ASR 文本中自动提取高频词，用 LLM 分类标注，生成候选术语表

---

## 实现方案

### 模块 `scripts/discover_terms.py`

| 步骤 | 功能 | 说明 |
|:----|:------|:------|
| 1. 文本加载 | 支持原始文本或 ASR JSON 段输入 | 自动提取 ja/transcription 字段 |
| 2. 高频词提取 | 正则分词 + 频率统计 + 过滤 | 去掉 ASCII/数字/过短词 |
| 3. LLM 标注 | 用 Sakura-14B 分类并翻译 | 分类：character/place/term/other |
| 4. 术语表生成 | 输出 JSON 格式，含分类和频率 | 可直接导入 glossary.py |

---

## 结论

### 使用方式

```bash
# 从原始文本提取
python scripts/discover_terms.py --input asr_text.txt --output glossary.json

# 从 ASR 段 JSON 提取 + LLM 标注
python scripts/discover_terms.py --input segments.json --output glossary.json --llm

# 自定义最低频率
python scripts/discover_terms.py --input asr_text.txt --output glossary.json --min-freq 5

# 运行测试
python scripts/discover_terms.py --evaluate
```

### 注意事项

- 分词依赖简单的正则，对日语复合词可能不够精确
- 建议使用 `--min-freq 3` 避免噪声
- LLM 标注结果需要人工审核后再导入正式术语表
