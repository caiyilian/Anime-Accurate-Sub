# S15.4 翻译组字幕对齐基线

> 日期：2026-07-15  
> 视频：`data/轻音少女_全集`（无插入广告版本）  
> 参考字幕：雪飘轻音部 `data/S1/K-ON! 2009 - EP01.ass` 至 `EP14.ass`

## 评测方法

新增 `scripts/eval_fansub_quality.py`，按时间轴重叠关系将 Pipeline 生成字幕与翻译组
ASS 正文对齐。该方法允许 ASR 和字幕组使用不同分句，不会仅因一拆多或多合一而判错。

每集预测文件按质量阶段选择：优先读取双裁判 MQM 的 `mqm_reviewed.json`，其次读取
多 Agent 审查的 `reviewed.json`，只有审查阶段尚未完成时才回退到 Sakura 基础译文
`translated.json`。因此最终整季报告衡量的是实际交付字幕，而不是审查前的中间产物。

默认只评估对白样式（Default、YUI、MUGI、MIO、RITU、AZUSA），排除 OP/ED、
歌词、Staff、标题和屏幕文字。指标包括：

- 参考对白覆盖率；
- 分段无关的字符 chrF、字符 F1 和编辑相似度；
- ASR 长段、乱码替换字符、空文本等健康度指标；
- 每集最差的 20 个时间轴对齐样本，便于人工定位根因。

## 当前 14 集基线

| 指标 | 结果 |
|:--|--:|
| Pipeline 预测段数 | 699 |
| 翻译组正文段数 | 5282 |
| 平均参考覆盖率 | **32.12%** |
| 平均 corpus chrF | **0.1518** |
| 平均字符 F1 | **0.3161** |
| 平均编辑相似度 | **0.0847** |
| 超过 20 秒的 ASR 段 | **176** |
| ASR 替换乱码字符 | **1811** |

完整机器可读结果见 `docs/evaluation/fansub_quality_baseline.json`。

## 根因判断

当前结果的首要瓶颈不是 Sakura 翻译模型，而是整集 ASR：

1. 主流程使用的 `.omo/anime-whisper-ct2` 在长音频中大约每 30 秒只输出一个大段；
2. 大段文本的时间戳经常只有不到 1 秒，无法与真实对白对齐；
3. 输出包含大量 `�` 和成人语料式幻觉，错误会完整传递给翻译模型；
4. 14 集平均只有约 50 段，而翻译组正文平均约 377 段。

因此在修复 ASR 模型和长音频分句以前，单独调整 Sakura Prompt 或更换翻译模型无法
实质改善端到端中文字幕质量。

## 复现命令

```bash
python scripts/eval_fansub_quality.py \
  --prediction-root output_clean \
  --reference-root data/S1 \
  --output docs/evaluation/fansub_quality_baseline.json
```
