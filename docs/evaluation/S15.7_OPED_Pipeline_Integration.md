# S15.7 OP/ED 检测接入主流程

## 问题

Sprint 7 已经验证 AniChapters 音频相关方案，但只保留了评估脚本和文档，正式
`anime_sub.py` 从未调用检测器。Anime Whisper 因此会把主题曲当对白识别，产生
看似流畅、实际无意义的日文；Sakura 又会把这些错误输入继续翻译成错误中文。

第 1 集真实 ASR 中的典型例子：

- `しデカシマシネバネにカンスト終業タイム...`
- `男子禁制のプリトコイツツカ日記帳ガード`

这不是翻译 prompt 可以解决的问题，必须在 ASR 与翻译之间过滤主题曲时间段。

## 实现

- 新增 `scripts/oped_detector.py`：
  - 通过 AnimeThemes API 搜索系列并按集数选择 OP/ED 版本；
  - 主题曲媒体和 API 元数据缓存到 `.omo/oped_cache`；
  - 以 ffmpeg 解码单声道音频，使用 SciPy 归一化相关定位主题曲；
  - API 与媒体下载支持 4 次指数退避，urllib 失败后回退
    `curl --retry-all-errors`；
  - 支持离线显式区间，例如 `--oped-range op:115.0-204.8`；
  - 仅移除中点落在主题曲区间内的 ASR 段，保留前后对白。
- 主流程在 ASR 完成后、写入 `asr_results.json` 前过滤 OP/ED，并写出：
  - `oped_ranges.json`：检测区间、相关系数和来源；
  - `oped_removed_segments.json`：被移除的原始 ASR 段，便于审计。
- CLI 新增：
  - `--oped-series`：AnimeThemes 系列名；
  - `--episode-number`：主题曲版本选择（未提供时从文件名推断）；
  - `--oped-range`：可重复的离线区间；
  - `--oped-best-effort`：显式允许检测失败后继续。默认严格失败，避免静默
    生成错误歌词字幕。
- 同时修复断点恢复问题：提取音频阶段已完成但 ASR 尚未完成时，主流程现在会
  重新定位工作目录内的 WAV，而不是把目录路径误传给 Anime Whisper。

- EP01：OP 122.47–200.12s，ED 1331.98–1412.68s；

- ED 后尾声对白从 1422.56s 保留。
