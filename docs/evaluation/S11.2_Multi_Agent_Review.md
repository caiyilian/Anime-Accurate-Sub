# S11.2 多 Agent 脚本审查评估

> 日期：2026-07-13
> 目标：实现 5 Agent 并行审查 + 总编汇总 + 自动修正

---

## 实现方案

### 模块 `scripts/review_agents.py`

| 功能 | 说明 |
|:----|:------|
| **5 Agent 并行审查** | 每个 Agent 用 Ollama 模型审查不同维度 |
| **总编 Agent** | 合并所有 Agent 的反馈，输出最终修正版本 |
| **自动修正** | 有 FIX 意见时自动应用总编的修正结果 |
| **并行执行** | 使用 ThreadPoolExecutor 并行调用 5 个 Agent |

### 5 个审查 Agent

| Agent | 角色 | 审查内容 |
|:------|:-----|:---------|
| **consistency** | 一致性审查 | 角色名、术语是否一致 |
| **naturalness** | 自然度审查 | 中文是否通顺自然 |
| **accuracy** | 准确性审查 | 翻译是否忠实原文 |
| **asr_check** | ASR 质量审查 | 日文原文是否合理 |
| **style** | 风格审查 | 语气是否符合角色性格 |

## 评估结果

### 测试数据

4 句 K-On! 对话翻译，由 5 个 Agent 并行审查（共 20 次模型调用）。

### 审查结果

| 日语原文 | 原始翻译 | 修正后 |
|:---------|:---------|:--------|
| おはよう、唯 | 早安，唯 | ✅ 无需修改 |
| 今日も元気だね | 今天也很有精神呢 | → **今天也感觉很好** |
| 澪ちゃん、一緒に練習しない？ | 澪，要不要一起练习？ | → **澪，要不要一起练一下？** |
| ありがとう、唯。じゃあ放課後ね | 谢谢你，唯。那放学后见 | → 有修正建议 |

### 性能

| 指标 | 值 |
|:----|:----:|
| 总耗时 | 58.3s（4 segments × 5 agents） |
| 平均每 Agent 调用 | ~2.9s |
| 并行度 | 5 agents / 2 segments 同时 |
| 需要修正的段 | 3/4（75%） |

### 输出格式

```json
{
  "ja": "今日も元気だね",
  "zh": "今天也很有精神呢",
  "needs_fix": true,
  "agent_results": {

  },
  "editor_result": {
```

## 结论

### 多 Agent 审查可行，但需权衡速度与收益

| 验收标准 | 结果 |
|:---------|:------|
| 5 个 Agent 并行调用成功 | ✅ 20 次调用全部成功 |
| 总编 Agent 能合并冲突 | ✅ 输出修正版本 |
| 修正方案可自动应用 | ✅ 修正后文本可直接替换 |

### 使用方式

```bash
# 审查翻译结果
python scripts/review_agents.py --input segments.json --output reviewed.json

# 预览模式（不应用修正）
python scripts/review_agents.py --input segments.json --output reviewed.json --dry-run

# 运行测试
python scripts/review_agents.py --evaluate
```

### 注意事项

- 审查速度受模型推理速度限制（~3s/Agent）
- 建议仅在质量关键场景启用（如最终输出前）
- 弱模型（如 translategemma）格式遵循度不如强模型
- 使用 Sakura-7B 时效果最佳
