## AniChapters 评估

### 测试方法

使用 [AniChapters](https://github.com/56cla/AniChapters) v6.0（Auto_Chap v4.2 引擎）在 K-On! 剧集上进行 OP/ED 检测。

**工作流程**：
1. 搜索 [animethemes.moe](https://animethemes.moe) 获取 K-On! 主题曲信息
2. 下载主题曲 .ogg 音频文件（首次运行，后续缓存）
3. 使用 librosa 加载音频，scipy 做互相关匹配
4. 输出章节文件（.chapters.txt）

### EP01 检测结果

```
CHAPTER01=00:00:00.000  Prologue
CHAPTER02=00:01:55.140  Opening    <- OP「Cagayake! GIRLS」
CHAPTER03=00:03:24.913  Episode
CHAPTER04=00:23:30.750  Ending     <- ED「Don't say lazy」
CHAPTER05=00:25:00.724  Epilogue
```

### EP02 检测结果

```
CHAPTER01=00:00:00.000  Prologue
CHAPTER02=00:00:52.150  Opening    <- OP「Cagayake! GIRLS」
CHAPTER03=00:02:21.923  Episode
CHAPTER04=00:23:30.790  Ending     <- ED「Don't say lazy」
CHAPTER05=00:25:00.764  Epilogue
```

### 结果分析

| 维度 | EP01 | EP02 | 一致性 |
|:----|:----:|:----:|:------:|
| OP 位置 | 01:55.140 | 00:52.150 | 位置因前情提要长度不同而异 |
| OP 时长 | 89.8s | 89.8s | 完全一致 |
| ED 位置 | 23:30.750 | 23:30.790 | 几乎一致（差 0.04s） |
| ED 时长 | 90.0s | 90.0s | 完全一致 |
| 主题曲下载 | 首次需网络 | 缓存复用 | 后续离线 |

**结论**：AniChapters 检测结果准确、跨集一致。

## 最终决策

### 选择：AniChapters（音频指纹匹配 + animethemes.moe 主题曲库）

**工作原理**：
```
animethemes.moe 主题曲库 -> 下载主题曲 .ogg
                                    |
剧集 MP4 -> ffmpeg 提取音频 -> librosa 加载
                                    |
                scipy 互相关匹配 -> 输出 OP/ED 时间戳
```

### 为什么选 AniChapters

| 优势 | 说明 |
|:----|:------|
| **精确** | EP01/EP02 ED 位置差仅 0.04s |
| **跨集一致** | 同一主题曲在不同剧集中识别稳定 |
| **自动获取主题曲** | 无需手动准备参考音频 |
| **缓存机制** | 首次下载后后续离线可用 |
| **成熟** | 17 stars，v6.0 发布，持续维护 |

### 其原理适用于我们的 pipeline

虽然 AniChapters 是一个独立 GUI 工具，但其核心算法（librosa + 互相关）可以直接集成：

```
1. 用户输入系列名称（如 K-On!）
2. 从 animethemes.moe 获取主题曲
3. 对每集进行音频相关匹配
4. 输出 OP/ED 时间戳 -> 跳过 ASR
```
