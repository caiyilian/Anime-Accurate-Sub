# S9.2 术语表系统评估

> 日期：2026-07-19（补充第一季全 14 集术语覆盖）
> 目标：实现术语表系统，通过在翻译 prompt 中注入术语映射来保证角色名和专有名词的翻译一致性

---

## 实现方案

### 术语表模块 `scripts/glossary.py`

| 功能 | 说明 |
|:----|:------|
| JSON 格式加载 | `{"terms": [{"ja": "平沢唯", "zh": "平泽唯"}, ...]}` |
| 文本格式加载 | JAVTrans 兼容：`平沢唯-平泽唯, 秋山澪-秋山澪` |
| Prompt 注入 | 自动生成"以下术语表的翻译必须严格遵守：{术语列表}" |
| 导出 | 支持 to_json() / to_text() 导出 |
| 环境变量 | `GLOSSARY_FILE` 指定默认术语表路径 |

### translate.py 集成

| 方式 | 用法 |
|:----|:------|
| CLI 参数 | `--glossary data/glossary/k-on_glossary.json` |
| 环境变量 | `GLOSSARY_FILE=data/glossary/k-on_glossary.json` |

### 术语表示例

`data/glossary/k-on_glossary.json` — 包含 57 个 K-On! 关键术语：

```
角色名: 平沢唯→平泽唯, 秋山澪→秋山澪, 田井中律→田井中律, 琴吹紬→琴吹紬, 中野梓→中野梓
昵称:   ムギ→小紬, あずにゃん→梓喵, 純ちゃん→小纯, さわちゃん→小佐和
术语:   軽音部→轻音部, 放課後ティータイム→放学后茶会, ギー太→吉太, 桜高祭→樱高祭
```

### 第一季全量补全依据

本次补全只扫描与源视频一一对应的 14 集日文字幕，不读取中文翻译组字幕。日文字幕中的代表性命中包括：`ムギ` 84 次、`梓` 50 次、`あずにゃん` 38 次、`うい` 34 次、`さわちゃん` 22 次、`ギー太` 12 次、`放課後ティータイム` 6 次。由此补齐中野梓、铃木纯、昵称、校名、乐队名和演出名等高频缺项。

中文翻译组字幕继续严格作为最终盲评参考，不参与术语发现、翻译 prompt 或译后改写。这样可以检测真实翻译能力，避免把参考答案提前注入生成流程。

同时将生僻字形 `䌷` 统一为现代字幕常用字形 `紬`。测试会检查关键映射及日文源词唯一性，避免重复条目导致 prompt 出现相互冲突的规则。

## 评估结果

### 有术语表 vs 无术语表

| 日语原文 | 无术语表 | 有术语表 | 说明 |
|:---------|:---------|:---------|:------|
| 澪ちゃん、一緒に練習しない？ | "澪酱，要不要一起练习？" | "澪，要不要一起练习？" | ✅ 术语表统一了角色名 |
| 唯ちゃん | "酱唯" ❌ | "小唯" ✅ | ✅ 术语表纠正误译 |
| 軽音部に入りたい | "想进轻音乐部" | "想进轻音部" | ✅ 术语表指定标准译名 |

### 空术语表不影响翻译

```
python scripts/translate.py --text "おはよう"  # 无术语表 → 正常工作
```

空术语表返回空 prompt_block，不修改原始 prompt，零开销。

### 模型兼容性

| 模型 | 术语表效果 | 说明 |
|:----|:---------|:------|
| Sakura-7B（推荐） | ✅ 良好 | 能正确遵循术语表指令，只输出翻译 |
| translategemma:4b | ⚠️ 弱模型会回显术语表 | 指令遵循能力弱，但术语映射仍生效 |

---

## 结论

### 术语表系统有效，建议启用

| 场景 | 建议 |
|:----|:------|
| 角色名统一 | ✅ 强制开启术语表 |
| 专有名词一致性 | ✅ 通过术语表锁定标准译名 |
| 空术语表 | ✅ 不影响翻译，零开销 |
| 多系列切换 | ✅ 不同系列使用不同术语表文件 |

### 使用方式

```bash
# 通过 CLI 参数
python scripts/translate.py \
  --text "澪ちゃん、一緒に練習しない？" \
  --glossary data/glossary/k-on_glossary.json

# 通过环境变量
set GLOSSARY_FILE=data/glossary/k-on_glossary.json
python scripts/translate.py --text "おはよう、唯"
```

### 术语表格式

```json
{
  "terms": [
    {"ja": "平沢唯", "zh": "平泽唯"},
    {"ja": "軽音部", "zh": "轻音部"}
  ]
}
```
