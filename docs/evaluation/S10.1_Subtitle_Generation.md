# S10.1 字幕生成评估：pysubs2 SRT/ASS + 时间轴优化

> 日期：2026-07-13
> 目标：实现基础字幕生成模块，支持 SRT/ASS 格式输出，应用时间轴优化规则

---

## 实现方案

### 模块 `scripts/subtitle_gen.py`

| 功能 | 说明 |
|:----|:------|
| SRT 输出 | 标准 SRT 格式，播放器兼容 |
| ASS 输出 | 带样式模板的高级字幕格式 |
| 时间轴优化 | 重叠修复 + 最小时长 + CPS 检查 + 换行 |
| 样式模板 | 2 套：anime（默认）、anime_bilingual（双语） |

### 时间轴优化规则

| 规则 | 参数 | 说明 |
|:----|:----:|:------|
| 重叠修复 | gap=0.05s | 相邻字幕至少间隔 50ms |
| 最小时长 | 1.0s | 字幕最短显示 1 秒 |
| 最大时长 | 7.0s | 字幕最长显示 7 秒 |
| CPS 上限 | 15 | 每秒最多 15 个字符（阅读速度） |
| 换行 | 30 chars | 超过 30 字符自动换行 |

---

## 评估结果

### 测试数据

10 句连续对话，包含 3 个故意设置的重叠（模拟真实 ASR 输出）。

### 时间轴优化效果

| 指标 | 优化前 | 优化后 | 说明 |
|:----|:------:|:------:|:------|
| 重叠数 | 3 | 0 | 所有重叠已修复 |
| 最小时长 | 0.5s | 1.0s | 短字幕补足到 1s |
| 平均 CPS | 5.5 | 4.8 | 阅读速度合理 |
| 最长行 | 45 chars | 自动换行 | 长句正确断开 |

### 输出文件

| 格式 | 大小 | 说明 |
|:----|:----:|:------|
| SRT | 782 bytes | 标准格式，所有播放器兼容 |
| ASS | 1686 bytes | 带样式信息，支持高级渲染 |

## 结论

### 字幕生成模块可用，时间轴优化有效

| 验收标准 | 结果 |
|:---------|:------|
| SRT/ASS 文件播放器可正常加载 | ✅ 标准格式，测试通过 |
| 时间轴优化后无重叠、CPS 合理 | ✅ 重叠 3→0，CPS 平均 4.8 |

### 使用方式

```bash
# 生成 SRT
python scripts/subtitle_gen.py --input segments.json --output output.srt

# 生成 ASS（带样式）
python scripts/subtitle_gen.py --input segments.json --output output.ass --style anime

# 运行评估
python scripts/subtitle_gen.py --evaluate
```

### 输入 JSON 格式

```json
[
  {"start": 0.0, "end": 3.5, "text": "早安啊，唯"},
  {"start": 3.2, "end": 6.0, "text": "啊，早安！", "speaker": "SPEAKER_00"}
]
```
