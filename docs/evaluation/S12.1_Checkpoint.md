# S12.1 断点续传评估

> 日期：2026-07-13
> 目标：实现断点续传机制，支持中断重启后自动跳过已完成阶段

---

## 实现方案

### 模块 `scripts/checkpoint.py`

| 类 | 功能 |
|:---|:------|
| **Checkpoint** | 阶段标记 + 状态持久化 + 重启恢复 |
| **JSONLStore** | 原子写入 + 中间结果存储 |

### Pipeline 阶段

```
extract_audio → asr → translate → subtitle → quality_check
```

### 核心机制

| 功能 | 实现方式 |
|:----|:---------|
| **阶段标记** | JSON 文件记录每个阶段的状态（completed/failed/pending） |
| **原子写入** | 先写 .tmp 文件，再 rename 替换原文件 |
| **重启恢复** | 加载 checkpoint.json，自动跳过已完成阶段 |
| **中间结果** | JSONL 格式逐条写入，每条独立原子操作 |
