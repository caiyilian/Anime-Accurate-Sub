# S16.5 视频字幕效果预览

## 功能

- 从任意起点截取 0.5–60 秒，使用当前 ASS 和 libass 生成浏览器可播放的 H.264/AAC MP4。
- 可选择 320–1920 像素宽度；默认 960 像素、8 秒、CRF 27、`veryfast`，兼顾生成速度和样式可见性。
- 先在原分辨率渲染 ASS 再缩放，预览保留字号、描边、颜色、位置和角色样式的相对效果。
- 快速寻址会把片段时间戳归零；滤镜链会先把视频 PTS 恢复为整集绝对时间供 ASS 匹配，渲染后再归零，保证 844 秒的字幕能出现在从 842 秒截取的预览中。
- 只复制很小的 ASS 到输出目录的随机临时文件，不复制完整源视频；命令使用参数数组，不经过 shell。
- Web 任务结果新增“字幕预览”入口，输入起点、时长和宽度后生成短片并直接加载到 `<video>` 播放器。
- CLI 可用于流水线外的现有视频与 ASS，包括人工校对后的成片抽查。

## CLI

```powershell
python scripts/video_preview.py video.mp4 `
  --subtitle episode.ass --output episode_preview.mp4 `
  --start 844.2 --duration 8 --width 960
```

可使用 `--mute` 去除音轨，`--crf` 和 `--preset` 调整编码速度。程序优先使用 `.omo/ffmpeg-libass` 中的构建，也可通过 `FFMPEG_PATH` 或 `--ffmpeg` 指定其他支持 libass 的 FFmpeg。

## Web API

`POST /api/jobs/{id}/preview` 接收 JSON：

```json
{"start": 844.2, "duration": 8, "width": 960, "mute": false}
```

返回生成时间、文件大小、实际选项和受目录边界保护的预览下载 URL。预览文件名固定为 `<视频名>_preview.mp4`，再次生成会更新同一任务的预览，不影响完整压制版。

## 限制

这是短片式所见即所得预览，不是浏览器内逐帧实时合成。首次生成仍取决于磁盘速度、起点位置和编码器；使用快速寻址、短时长和低分辨率后，典型成本远低于重新压制整集。
