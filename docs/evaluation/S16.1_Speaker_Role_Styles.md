# S16.1 说话人角色颜色与名称映射

## 功能

- 翻译阶段保留输入片段的 `speaker` 元数据。
- JSON 映射将 `SPEAKER_00` 等聚类 ID 人工确认成角色名和 `#RRGGBB` 颜色。
- ASS 为每个角色生成独立样式，设置角色颜色并在字幕前显示 `角色名：`。
- SRT 不写 ASS 控制码，只保留可读的角色名前缀。
- 未映射或没有说话人信息的片段继续使用原 `anime` 样式，不影响现有流程。

示例配置见 `docs/examples/speaker_roles.json`。

## 使用

```powershell
python scripts/anime_sub.py episode.mp4 `
  --speaker-map docs/examples/speaker_roles.json

python scripts/subtitle_gen.py `
  --input translated.json --output episode.ass --style anime `
  --speaker-map docs/examples/speaker_roles.json
```

若只需要颜色、不显示角色名，可在字幕生成器中加 `--no-speaker-prefix`。

## 设计限制

声纹聚类 ID 不是可靠角色身份，因此本阶段不自动猜测角色名。映射必须由用户或后续人工
校对确认，再用于同一系列的一致样式。这避免把错误聚类直接显示成错误角色。
