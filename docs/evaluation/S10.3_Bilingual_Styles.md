# S10.3 双语字幕 + ASS 样式模板 + Aegisub 校对出口

> 日期：2026-07-13
> 目标：扩展字幕生成模块，支持双语字幕、多套样式模板、Aegisub 兼容导出

---

## 实现方案

### subtitle_gen.py 扩展内容

| 功能 | 说明 |
|:----|:------|
| **双语字幕** | JA+ZH 同屏显示，支持 top_ja/top_zh 两种布局 |
| **4 套样式模板** | anime / anime_bilingual / classic / karaoke |
| **Aegisub 兼容** | ASS v4.00+ 格式，完整 [V4+ Styles] 头 |
| **CLI 切换** | `--style` 切换样式，`--bilingual` 启用双语 |

### 样式模板

| 样式名 | 字体 | 大小 | 描边 | 阴影 | 适用场景 |
|:-------|:----|:----:|:----:|:----:|:---------|
| **anime** | Microsoft YaHei | 28px | 2 | 1 | 默认动漫字幕 |
| **anime_bilingual** | Microsoft YaHei | 24px | 2 | 1 | 双语字幕（字号更小） |
| **classic** | Arial | 26px | 1 | 0 | 经典风格，无阴影 |
| **karaoke** | Microsoft YaHei | 32px | 3 | 1 | OP/ED 歌词字幕 |

### 使用方式

```bash
# 单语 SRT
python scripts/subtitle_gen.py --input segments.json --output output.srt

# 单语 ASS（指定样式）
python scripts/subtitle_gen.py --input segments.json --output output.ass --style classic

# 双语 ASS
python scripts/subtitle_gen.py --input bilingual.json --output output.ass --bilingual

# 双语 ASS（中文在上）
python scripts/subtitle_gen.py --input bilingual.json --output output.ass --bilingual --bilingual-layout top_zh

# 列表样式
python scripts/subtitle_gen.py --list-styles

# 运行评估
python scripts/subtitle_gen.py --evaluate
```

### 输入格式

单语：
```json
[{"start": 0.0, "end": 3.5, "text": "早上好"}, ...]
```

双语：
```json
[{"start": 0.0, "end": 3.5, "text": "早上好", "ja": "おはよう"}, ...]
```
