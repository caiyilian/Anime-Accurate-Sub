# S15.2 智能默认值评估

> 日期：2026-07-13
> 目标：自动检测硬件，推荐最优 pipeline 参数

---

## 实现方案

### 模块 `scripts/hardware.py`

| 检测项 | 方式 | 说明 |
|:-------|:-----|:------|
| GPU | nvidia-smi / PyTorch | 型号、VRAM 总量/空闲 |
| CPU | psutil / os.cpu_count() | 物理核/逻辑核数 |
| RAM | psutil | 总量/可用 |
| 平台 | platform | 系统/版本/Python 版本 |

### 推荐参数

| 参数 | 推荐逻辑 |
|:----|:---------|
| **翻译模型** | VRAM >= 16GB → Sakura-14B 本机 / >= 8GB → Sakura-7B / >= 4GB → GalTransl / 否则用服务器 |
| **ASR batch** | VRAM >= 12GB → 8 / >= 8GB → 4 / >= 4GB → 2 / 否则 1 |
| **并行数** | CPU 核数 / 2（上限 4） |
| **质量审查** | VRAM >= 12GB 时启用 |

### 集成到 CLI

```bash
python scripts/anime_sub.py video.mp4 --auto
```

`--auto` 会自动检测硬件并设置最优参数。

## 评估结果

### 本机检测结果

| 项目 | 值 |

| GPU | NVIDIA GeForce RTX 3060 |

### 推荐参数

| 参数 | 推荐值 | 原因 |
|:----|:-------|:------|
| 翻译模型 | Sakura-7B (本机) | VRAM 12GB >= 8GB |
| ASR batch | 8 | VRAM 12GB >= 12GB |
| 并行数 | 4 | 24核/2=12, 上限4 |
| 质量审查 | 启用 | VRAM 12GB >= 12GB |

python scripts/hardware.py
