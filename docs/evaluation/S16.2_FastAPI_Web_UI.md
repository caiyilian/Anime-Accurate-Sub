# S16.2 FastAPI Web UI

## 功能范围

- 浏览器上传常见视频文件，并选择 Sakura、GalTransl、Qwen 或 External 翻译后端。
- 可配置翻译批大小和质量检查，后台进程调用现有 `scripts/anime_sub.py`，不复制流水线逻辑。
- 任务列表从 `checkpoint.json` 读取真实完成阶段，同时显示进程状态、当前阶段和日志尾部。
- SRT、ASS、压制后 MP4、译文 JSON 和质量报告生成后可直接下载。
- 任务元数据、日志、输入和输出保存在 `.omo/web_jobs/<job-id>/`，服务重启后仍能查看历史任务；重启时失去进程句柄的运行中任务标记为 `interrupted`。

## 安全边界

- 默认监听 `127.0.0.1`，不会主动暴露到局域网。
- 翻译后端使用白名单，流水线命令用参数数组启动，不经过 shell。
- 上传文件名会移除路径和 Windows 非法字符，只接受视频扩展名。
- 下载接口会解析并检查最终路径，只允许访问对应任务输出目录内的受支持结果文件。

## 安装与启动

```powershell
pip install -e ".[web]"
python scripts/web_ui.py
```

随后打开 `http://127.0.0.1:8000`。可用 `--port` 修改端口，或用 `--job-root` 指定任务目录。只有明确需要其他机器访问时才应设置 `--host 0.0.0.0`，并同时配置防火墙和访问控制。

## API

- `GET /api/health`：健康检查。
- `GET /api/jobs`：任务列表、checkpoint 进度、日志和结果。
- `GET /api/jobs/{id}`：单个任务详情。
- `POST /api/jobs`：以 multipart 表单上传视频并启动任务。
- `GET /api/jobs/{id}/files/{path}`：下载经过目录边界检查的任务结果。
