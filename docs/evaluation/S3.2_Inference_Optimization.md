# S3.2 Faster-Whisper 推理优化报告
> 日期: 2026-07-11
> 模型: Anime Whisper (quantumcookie/anime-whisper-ct2-fp16)
> 测试集: 200 条日语语音片段 (904s)
> 环境: Python 3.13 + torch 2.11.0+cu128, RTX 3060 12GB

## 详细分析

### 最优精度配置
- **int8f16_b8_novad**: Avg CER=0.1299, RTF=0.1022

### 最优速度配置
- **int8f16_b8_vad**: RTF=0.0958, Avg CER=0.2654

### 最优均衡配置
- **int8f16_b8_novad**: RTF=0.1022, Avg CER=0.1299

### 量化影响

| 量化 | batch=1 VAD=on | vs baseline |
|------|:--------------:|:-----------:|
| float16 | CER=0.3056 RTF=0.1029 | CER +0.0% RTF +0% |
| int8_float16 | CER=0.2805 RTF=0.1009 | CER -8.2% RTF +2% |
| int8 | CER=0.2805 RTF=0.1028 | CER -8.2% RTF +0% |

### VAD 影响

- VAD ON:  CER=0.3056  RTF=0.1029
- VAD OFF: CER=0.1505  RTF=0.1123

### BatchedInferencePipeline 影响

- float16: batch=1 RTF=0.1029 → batch=8 RTF=0.0994 (快 4%)
- int8_float16: batch=1 RTF=0.1009 → batch=8 RTF=0.0958 (快 5%)

## 推荐配置

**生产环境推荐**: int8f16_b8_novad
- compute_type=int8_float16
- batch_size=8
- VAD=OFF
- RTF=0.1022 | Avg CER=0.1299
