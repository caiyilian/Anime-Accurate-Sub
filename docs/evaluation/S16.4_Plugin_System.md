# S16.4 插件系统架构

## 插件类型与契约

| 类型 | factory 输入 | factory 返回对象的要求 | 流水线接入点 |
|---|---|---|---|
| `translator` | 完整配置字典 | `translate`、`translate_batch`、`name` 方法 | `TranslatorAdapter.from_config` |
| `asr` | 完整配置字典 | `transcribe(audio_path)` 方法 | `anime_sub.run_asr` |
| `subtitle_style` | 样式覆盖配置 | `pysubs2.SSAStyle` 可接受的字典 | `subtitle_gen.generate` |

注册表会校验插件名、重复注册和返回对象契约。内置 Sakura、GalTransl、Qwen、External、Anime Whisper 以及所有内置 ASS 样式也走同一注册表，因此插件不是旁路接口。

## 本地插件

插件是会在当前 Python 进程中执行的代码，只能加载可信文件：

```powershell
python scripts/anime_sub.py episode.mp4 `
  --plugin docs/examples/plugins/demo_plugin.py `
  --backend demo_prefix --subtitle-style demo_pink

python scripts/anime_sub.py `
  --plugin docs/examples/plugins/demo_plugin.py --list-plugins
```

本地模块需要提供 `register_plugins(registry)` 或 `register(registry)`。示例见 `docs/examples/plugins/demo_plugin.py`，其中同时包含前缀翻译器、读取预计算 JSON 的 Sidecar ASR 和粉色字幕样式。显式 `--plugin` 可重复使用，加载同一路径两次会去重。

## 安装包 Entry Point

第三方 Python 包可在自己的 `pyproject.toml` 声明：

```toml
[project.entry-points."anime_accurate_sub.plugins"]
my_plugin = "my_package.plugin:register_plugins"
```

入口函数接收注册表并调用 `registry.register(kind, name, factory, ...)`。项目启动时自动发现该组；单个损坏的第三方入口会记录错误但不会阻止其他插件加载。开发者可用 `python scripts/plugin_system.py` 查看发现结果和已注册插件。

## 覆盖与配置

- 插件名使用小写字母、数字、点、短横线或下划线，并以小写字母开头。
- 同类型同名默认拒绝；有意覆盖时必须在注册中显式使用 `replace=True`。
- factory 收到完整配置，建议在以插件名命名的配置节中读取参数。
- ASR 引擎按后端名和 `asr` 配置缓存，同一批多集处理只加载一次模型。
- Web UI 不接受任意插件路径，避免远程页面触发代码执行；插件加载保留在本地 CLI 的显式参数中。
