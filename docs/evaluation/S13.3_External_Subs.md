# S13.3 外挂字幕优先模式评估

> 日期：2026-07-13
> 目标：检测视频内嵌字幕轨道，优先提取已有字幕，避免重复 ASR/翻译

---

## 实现方案

### 模块 `scripts/extract_subs.py`

| 功能 | 说明 |
|:----|:------|
| **轨道检测** | 用 ffprobe 检测视频中的内嵌字幕轨道 |
| **智能提取** | 按语言优先级提取最佳字幕（zh > ja > en） |
| **决策逻辑** | 有中文直接用、有日文作参考、没有则走 ASR |
| **批量处理** | 支持 `--batch` 批量提取 |

### 语言优先级

| 优先级 | 语言 | 决策 |
|:------:|:----|:------|
| 4 | 中文 (chi/zho/zh) | 直接使用，跳过翻译 |
| 3 | 日文 (jpn/ja) | 提取作 ASR 参考 |
| 2 | 英文 (eng/en) | 备选参考 |
| 1 | 其他 | — |

## 结论

### 使用方式

```bash
# 查看视频字幕轨道信息
python scripts/extract_subs.py --video video.mp4 --info

# 提取最佳字幕（如有）
python scripts/extract_subs.py --video video.mp4

# 批量提取
python scripts/extract_subs.py --batch data/video/*.mp4

# 运行测试
python scripts/extract_subs.py --evaluate
```

### 集成方式

```python
from scripts.extract_subs import check_subtitle_available, extract_best_subtitle

info = check_subtitle_available("video.mp4")
if info["decision"] == "use_zh":
    result = extract_best_subtitle("video.mp4")
    # 直接使用提取的中文字幕
elif info["decision"] == "use_ja_as_reference":
    result = extract_best_subtitle("video.mp4")
    # 用日文字幕作 ASR 参考
else:
    # 走正常 ASR + 翻译 pipeline
    pass
```
