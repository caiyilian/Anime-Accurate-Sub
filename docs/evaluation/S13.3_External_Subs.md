# S13.3 外挂日文字幕优先模式评估

> 初版日期：2026-07-13
>
> 生产化复核：2026-07-19
>
> 目标：存在可信日文字幕时直接作为翻译源，跳过 ASR；不存在时安全回退 ASR。

## 复核结论

旧版 `scripts/extract_subs.py` 只能独立调用 ffprobe/ffmpeg 检测和导出轨道，`anime_sub.py` 从未调用它。旧报告中的“外挂字幕优先模式可用”仅指决策逻辑演示，实际主流程仍固定执行音频提取和 ASR；日文字幕也只被描述为“参考”，没有进入翻译。因此 Sprint 13.3 原先并未真正完成。

本次已把它改造成可用的生产阶段：

- 单视频可用 `--japanese-subtitle` 指定 SRT/ASS/SSA/VTT。
- 批处理可用 `--japanese-subtitle-dir` 按视频和字幕的集数唯一匹配。
- `--prefer-japanese-subtitles` 会依次寻找同目录日文 sidecar、日文内嵌文本轨；均不存在时回退 ASR。
- 日文源存在时，流水线阶段从 `extract_audio → asr` 替换为 `japanese_subtitle`，随后直接翻译。
- Web UI 支持随视频上传一份日文字幕，并显示真实的 `japanese_subtitle` checkpoint 进度。
- OP/ED 检测仍作用于日文字幕时间轴，歌词不会送入翻译和审查。

## 安全与可审计性

生产路径只选择日文文本轨，不会因为视频里有中文轨就把翻译组字幕送入生成流程：

1. 只接受 `.srt`、`.ass`、`.ssa`、`.vtt` 文本字幕；PGS 等位图轨不假装可直接转写。
2. 解析后必须包含有效时间轴、非空文本和日文假名；中文文件会被拒绝。
3. 批处理必须按集数得到唯一匹配；同一集有多个候选时直接报错，不按文件名顺序猜测。
4. 保存原字幕 SHA-256、路径、归档副本、原始/过滤后段数到 `japanese_source.json`。
5. 源文件内容变化时，自动使翻译、多 Agent、字幕生成、视频嵌入和质量报告 checkpoint 失效并重建。
6. 从外挂字幕切回 ASR 时同样使下游失效，避免复用不同源文本产生的旧译文。

中文翻译组字幕只允许在生成完成后用于盲评，不参与术语、上下文、总编或其他生成步骤。

## 《轻音少女》14 集验证

指定视频：`data/轻音少女_全集`。日文源：`.omo/k-on-jp-vcb/K-ON! S1E01.jp.srt` 至 `S1E14`。

| 指标 | 结果 |
|:-----|-----:|
| 成功唯一匹配 | 14/14 集 |
| 原始日文字幕 | 5,916 条 |
| 按已有 OP/ED 区间剔除歌词 | 497 条 |
| 可翻译对白 | 5,419 条 |
| 替换字符 / 非日文误用 | 0 |
| 当前 ASR 产物段数（对照） | 5,067 条 |
| 当前 ASR 对日文字幕 CER（对照） | 24.45% |

为确认 VCB 字幕不是错位版本，还将现有 ASR 与每集附近的日文字幕做模糊文本匹配：每集获得 124–192 个高相似匹配，平均相似度约 0.89；SRT 相对 ASR 语音起点的中位差为 `+0.23s` 至 `+0.41s`。这符合字幕通常略晚于发声的特征，没有发现广告插入导致的整体漂移，因此保留原时间轴，不做统一平移。

## 使用方式

单视频指定日文字幕：

```bash
python scripts/anime_sub.py "data/轻音少女_全集/轻音少女_第01集.mp4" \
  --japanese-subtitle ".omo/k-on-jp-vcb/K-ON! S1E01.jp.srt" \
  --oped-series "K-ON!" \
  --output-dir .omo/season_v5_jp
```

14 集按集数匹配：

```bash
python scripts/anime_sub.py \
  --batch "data/轻音少女_全集/*.mp4" \
  --japanese-subtitle-dir .omo/k-on-jp-vcb \
  --oped-series "K-ON!" \
  --output-dir .omo/season_v5_jp
```

自动寻找 sidecar/内嵌日文文本轨，找不到时回退 ASR：

```bash
python scripts/anime_sub.py video.mkv --prefer-japanese-subtitles
```
