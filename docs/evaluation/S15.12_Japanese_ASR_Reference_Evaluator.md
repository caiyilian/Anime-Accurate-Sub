# S15.12 日文字幕 ASR 基准工具

## 背景

中文翻译组字幕可以评估最终可读结果，但无法区分 ASR 原文错误与翻译模型错误。
项目已经下载了与 VCB-Studio 时间轴对齐的 14 集日文 SRT ZIP，此前没有工具直接
利用它，ASR 参数实验只能依赖置信度和中文译文指标。

## 实现

`scripts/eval_asr_reference.py` 可直接读取 ZIP，无需手工解压，并提供：

- 按集发现 `asr_results.json` 与 ZIP 内 `S1E01.jp.srt` 等参考文件；
- 从同集 `oped_ranges.json` 自动排除日文参考中的 OP/ED 歌词；
- NFKC、去空白/标点后的整集字符错误率（CER），不受字幕切段方式影响；
- 时间覆盖率与每集 20 个最差参考窗口，便于定位漏识别和近音错误；
- 1–14 集聚合报告及缺集清单。

## 第 1 集基线

使用 `data/轻音少女_全集` 第 1 集当前输出与
`K-ON! Retimed for [VCB-Studio] 1-14.zip` 对比：

- 日文参考对话 362 条；
- 时间覆盖率 98.07%；
- 整集 corpus CER 23.20%。

实验性的 `initial_prompt + hotwords` 将 CER 降到 21.71%，但最终中文 chrF 从
0.3831 降到 0.3779，原因是新的错误边界合并。因此该参数没有进入主线；新工具让
这种“日文变好但最终翻译变差”的权衡可以被明确量化。
