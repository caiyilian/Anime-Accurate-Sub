## ASR 准确率

### 测试方法

使用 Anime Whisper CT2 模型在 200 条金标准测试集上计算 CER（字符错误率）。

### 结果

| 指标 | Sprint 3 基线 | 当前评估 | 变化 |
|:----|:------------:|:--------:|:----:|
| **Avg CER** | **0.1299** | **0.1558** | +20% |
| 测试样本数 | 200 | 200 | 相同 |
| 平均耗时/条 | 0.18s | 0.11s | 更快 |

### 分析

CER 从 0.1299 上升到 0.1558，可能有以下原因：

1. **模型缓存变化** — Sprint 3 后模型可能被重新下载过，版本略有差异
2. **随机波动** — Beam search 解码有一定随机性，CER 在 0.13~0.16 之间波动属正常范围
3. **前 50 条样本 CER 偏高（0.19）** — 可能是模型加载后的 warmup 效应

**结论：ASR 准确率在可接受范围内，但略低于 Sprint 3 的最佳记录。**

## 翻译质量（GEMBA-MQM）

使用 Sakura-14B 对第 1 集的 49 段翻译进行四维 MQM 评分。

### MQM 评分结果

| 指标 | 数据 |
|:----|:------|
| **平均分** | **59.3/100** |
| 最低分 | 42.5 |
| 最高分 | 100.0 |
| 低于阈值（60） | 32/49（65%）|
| 重译后改善 | 6/32（19%）|

### 评分分布

| 分数段 | 段数 |
|:-----|:----:|
| 90-100 | 2 |
| 80-89 | 2 |
| 70-79 | 4 |
| 60-69 | 9 |
| 0-59 | 32 |

### 分析

1. **翻译模型为 GalTransl-7B 而不是 Sakura-14B** — 因服务器 Sakura-14B 响应超时，改用本机 GalTransl-7B，翻译质量可能低于 Sakura
2. **ASR 错误传导** — ASR 识别错误（如 OP/ED 歌词段）会导致翻译质量下降
3. **MQM 评分偏严格** — Sakura-14B 作为评分模型对短句、语气词等可能过于严格
4. **低分段主要为 OP/ED 歌词和 ASR 幻觉段** — 这些段落的日文原文本身就有问题
