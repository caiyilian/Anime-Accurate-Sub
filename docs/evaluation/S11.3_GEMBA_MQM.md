# S11.3 GEMBA-MQM 翻译质量评估

> 日期：2026-07-13
> 目标：实现基于 MQM 框架的翻译质量评估，支持低分段落自动重译

---

## 实现方案

### 模块 `scripts/gemba_mqm.py`

| 功能 | 说明 |
|:----|:------|
| **MQM 四维评分** | 准确性(35%) + 流畅度(25%) + 术语(20%) + 风格(20%) |
| **评分解析** | 从 LLM 回复中提取数值评分（0-100） |
| **自动重译** | 评分低于阈值（默认 60）时自动重新翻译 |
| **重译验证** | 重译后重新评分，对比改进效果 |

### MQM 评分维度

| 维度 | 权重 | 说明 |
|:----|:----:|:------|
| accuracy | 35% | 是否准确传达了原文含义 |
| fluency | 25% | 中文是否通顺自然 |
| terminology | 20% | 术语和角色名是否一致 |
| style | 20% | 语气风格是否适合角色和场景 |

---

## 评估结果

### 测试数据

5 段翻译，包含 1 段故意翻译较差的内容（"ごめん、遅刻した" → "对不起我迟到了今天早上闹钟没响"）。

### 评分结果

| 日语原文 | 中文翻译 | 总分 | 准确性 | 流畅度 | 术语 | 风格 |
|:---------|:---------|:---:|:-----:|:-----:|:---:|:---:|
| おはよう、唯 | 早安，唯 | **93.0** | 95 | 95 | 95 | 85 |
| 今日も元気だね | 今天也很有精神呢 | **82.8** | 90 | 85 | 75 | 75 |
| 澪ちゃん、一緒に練習しない？ | 澪，要不要一起练习？ | **84.8** | 90 | 85 | 85 | 75 |
| ありがとう、唯。じゃあ放課後ね | 谢谢你，唯。那放学后见 | **84.8** | 90 | 85 | 85 | 75 |
| ごめん、遅刻した | 对不起我迟到了今天早上闹钟没响 | **65.2** | 70 | 75 | 55 | 55 |

### 分析

- 高质量翻译（1-4）得分 82-93，区分度良好
- 低质量翻译（5）得分 65.2，明显低于其他
- 自动重译阈值 60 时，第 5 段未触发重译（65.2 > 60）
- 降低阈值到 50 可避免误触发，提高阈值到 70 可捕获更多问题

---

## 结论

### GEMBA-MQM 评分有效，建议启用

| 验收标准 | 结果 |
|:---------|:------|
| 翻译质量评分输出 | ✅ 四维评分 + 总分 |
| 低分段落可重新翻译 | ✅ 自动重译 + 重评对比 |

### 使用方式

```bash
# 评分翻译结果
python scripts/gemba_mqm.py --input segments.json --output scored.json

# 评分 + 自动重译低分段
python scripts/gemba_mqm.py --input segments.json --output scored.json --retranslate

# 自定义阈值
python scripts/gemba_mqm.py --input segments.json --output scored.json --retranslate --threshold 70

# 运行测试
python scripts/gemba_mqm.py --evaluate
```

### 整合建议

| 阈值 | 效果 |
|:----|:------|
| 50 | 宽松，只重译很差的内容 |
| 60 | 默认，平衡准确率和召回率 |
| 70 | 严格，捕获更多潜在问题 |
