# S15.1 全流程 CLI 集成评估

> 日期：2026-07-13
> 目标：所有模块串联为一条 CLI 命令 `anime-sub video.mp4`

---

## 实现方案

### 模块 `scripts/anime_sub.py`

| 命令 | 功能 |
|:----|:------|
| `anime_sub.py video.mp4` | 全流程处理单个视频 |
| `anime_sub.py --batch *.mp4` | 批量处理多个视频 |
| `anime_sub.py --test` | 模拟运行测试 |
| `anime_sub.py --version` | 版本信息 |

### Pipeline 阶段

```
extract_audio → asr → translate → subtitle → quality_check
    (ffmpeg)   (模拟)  (Adapter)   (pysubs2)  (可选)
```

### 已串联的模块

| 阶段 | 模块 | 说明 |
|:----|:-----|:------|
| 音频提取 | ffmpeg subprocess | 16kHz mono WAV |
| 翻译 | `translator_adapter.py` | 支持 4 后端切换 |
| 系列记忆 | `series_memory.py` | 可选注入角色信息 |
| 字幕生成 | `subtitle_gen.py` | SRT + ASS 双格式 |
| 质量审查 | `quality_check.py` | 可选启用 |
| 断点续传 | `checkpoint.py` | 自动跳过已完成阶段 |

### CLI 参数

| 参数 | 说明 |
|:----|:------|
| `--output-dir` | 输出目录 |
| `--backend` | 翻译后端 (sakura/qwen/galtransl/external) |
| `--config` | 翻译配置文件 |
| `--memory` | 系列记忆 JSON |
| `--quality-check` | 启用质量审查 |

## 结论

### 使用方式

```bash
# 基本用法
python scripts/anime_sub.py video.mp4

# 指定翻译后端和系列记忆
python scripts/anime_sub.py video.mp4 --backend sakura --memory k-on_memory.json

# 启用质量审查
python scripts/anime_sub.py video.mp4 --quality-check

# 批量处理
python scripts/anime_sub.py --batch data/video/*.mp4

# 运行测试
python scripts/anime_sub.py --test
```
