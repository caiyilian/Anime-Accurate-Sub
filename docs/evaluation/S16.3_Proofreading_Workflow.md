# S16.3 人工校对工作流

## 能力

- 从 `translated.json` 导出可移植的 JSON 校对稿，可选择只导出质量报告 `review_queue` 中的可疑片段。
- 校对稿包含行号、时间轴、日文、当前译文、修正译文、质量规则和源文件 SHA-256，可离线编辑后再导入。
- 导入前统一验证 SHA-256、原译文、索引和起始时间；任一冲突会整批拒绝，不产生半完成修改。
- 成功导入会备份原始译文 JSON，原子更新源文件，并在片段内与独立 JSONL 中同时记录修改前后文本、时间、操作者和备注。
- 可重新生成 SRT/ASS；原翻译模型和 fallback 来源继续保留，人工修正以 `proofread_status=corrected` 标记。
- 终端交互模式支持逐条查看日文、当前译文和质量原因，回车保留、输入新译文修正。
- Web 任务结果新增“人工校对”入口，可筛选可疑行、直接编辑译文并保存；保存后自动重建 SRT/ASS，并提示重新生成已经过期的压制视频。

## 命令

```powershell
python scripts/proofread.py export `
  --input output/episode/translated.json `
  --quality-report output/episode/quality_report.json `
  --only-review --output review.json

# 编辑 review.json 中的 corrected_text 后导入并重建字幕
python scripts/proofread.py apply `
  --input output/episode/translated.json `
  --sheet review.json --regenerate --operator editor-name

python scripts/proofread.py interactive `
  --input output/episode/translated.json `
  --quality-report output/episode/quality_report.json
```

`--force` 只应在人工确认源文件变化不会造成错行后使用。默认的冲突检查是为防止把旧校对稿应用到重新 ASR 或重新翻译后的时间轴。

Web UI 的保存接口执行同一套 SHA-256、原译文和时间轴冲突检查。若页面打开后任务被重新翻译，保存会返回冲突而不是覆盖新结果。
