## 实现方案

### 模块 `scripts/series_memory.py`

| 类/函数 | 功能 |
|:--------|:------|
| **SeriesMemory** | 一致性记忆管理：加载/保存/注入 |
| **create_k_on_memory()** | 加载 K-On! 第一季生产记忆（9 角色 + 15 术语） |
| **data/series_memory/k-on_s1.json** | 可直接传给正式流水线的角色关系、说话风格与称呼记忆 |

### series_memory.json 格式

```json
{
  "series_name": "K-On!",
  "characters": {
    "Yui": {
      "full_name_ja": "平沢唯",
      "full_name_zh": "平泽唯",
      "nicknames": ["唯", "小唯"],
      "speech_style": "genki, casual, airheaded",
      "relationships": {"Mio": "friend", "Ritsu": "friend"},
      "catchphrases": ["ふにゃふにゃ"]
    }
  },
  "terms": {
    "軽音部": {"zh": "轻音部", "description": "club name"}
  }
}
```

## 评估结果

### 生产记忆补全

旧示例缺少中野梓、真锅和、铃木纯，并保留了错误字形“琴吹䌷”；同时 `notes` 和 `catchphrases` 只被保存、没有注入模型。本次改为项目内置的第一季 JSON，统一为“琴吹紬”，补齐 9 名主要角色、15 个系列术语和第一季时间线。Prompt 使用中文标题并实际包含系列说明、称呼映射、角色关系、说话风格和固定说法。

所有姓名、昵称和固定术语都会与 `data/glossary/k-on_glossary.json` 自动比对，测试阻止两套质量约束产生冲突。中文翻译组字幕不参与记忆内容生成，只用于最终盲评。

## 结论

### 使用方式

```bash
# 创建 K-On! 示例记忆
python scripts/series_memory.py --sample --output k-on_memory.json

# 正式流水线直接使用项目内置文件
python scripts/anime_sub.py episode.mp4 --memory data/series_memory/k-on_s1.json

# 查看记忆内容
python scripts/series_memory.py --view k-on_memory.json

# 注入到翻译 prompt
python scripts/series_memory.py --inject k-on_memory.json --prompt "翻译：おはよう"

# 创建自定义系列记忆
python scripts/series_memory.py --create --series "My Anime" --output memory.json
python scripts/series_memory.py --input memory.json --add-char Yui 平沢唯 平泽唯 "genki"
python scripts/series_memory.py --input memory.json --add-term 軽音部 轻音部 "club"

# 运行测试
python scripts/series_memory.py --evaluate
```

### 代码中使用

```python
from scripts.series_memory import SeriesMemory
from scripts.translator_adapter import TranslatorAdapter

mem = SeriesMemory("k-on_memory.json")
adapter = TranslatorAdapter.from_config(config)

prompt = mem.inject_into_prompt("将下面的日语文本翻译成中文：おはよう")
# prompt 现在包含角色信息和术语表
result = adapter.translate("おはよう")
```
