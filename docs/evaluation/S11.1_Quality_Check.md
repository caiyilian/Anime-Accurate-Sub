# S11.1 质量审查评估：规则检查器 + 可疑行检测

> 日期：2026-07-13
> 目标：实现规则检查器和可疑行检测，为字幕质量提供自动化保障

---

## 实现方案

### 模块 `scripts/quality_check.py`

| 功能 | 说明 |
|:----|:------|
| **规则检查** | 时长/CPS/空翻译/行数/术语一致性/可疑模式 |
| **可疑行检测** | 空翻译标记/BGM 干扰/ASR 幻觉/短时长长文本 |
| **JSON 报告** | 结构化问题列表，含严重等级（error/warning/info） |
| **HTML 报告** | 可视化审查页面，可直接在浏览器中查看 |

### 检查规则

| 规则 | 严重等级 | 阈值 | 说明 |
|:----|:--------:|:----:|:------|
| `duration_too_short` | warning | < 1.0s | 字幕显示时间太短 |
| `duration_too_long` | warning | > 7.0s | 字幕显示时间太长 |
| `cps_too_high` | warning | > 15 | 阅读速度过快 |
| `cps_too_low` | info | < 1.5 | 可能为 BGM 段 |
| `empty_translation` | error | = 0 | 翻译为空 |
| `too_many_lines` | info | > 2 | 行数过多 |
| `repeated_char` | warning | 5+ repeats | 疑似 ASR 幻觉 |
| `term_inconsistency` | warning | — | 术语表不一致 |
| `bgm_interference` | info | — | 有日文无翻译 |
| `possible_hallucination` | warning | < 0.3 | 唯一词比例过低 |

## 评估结果

### 测试数据

11 条字幕段，包含：
- 2 条空翻译
- 1 条超短时长（0.5s）
- 1 条可能是 BGM 干扰（CPS 过低）
- 2 条有日文原文但无翻译

### 检测结果

| 严重等级 | 数量 | 示例 |
|:--------|:----:|:------|
| **error** | 2 | 空翻译文本 |
| **warning** | 1 | 时长 0.5s < 最小 1.0s |
| **info** | 4 | CPS 0.0 可能为 BGM；有日文无翻译 |
| **总计** | 7 | — |

### 输出格式

**JSON 报告**：
```json
{
  "stats": {"total_segments": 11, "errors": 2, "warnings": 1, "info": 4},
  "issues": [
    {"severity": "error", "rule": "empty_translation", "segment_index": 1, "message": "..."},
    ...
  ]
}
```

**HTML 报告**：浏览器可直接打开的审查页面，含统计卡片和问题表格。

## 结论

### 使用方式

```bash
# 生成 JSON 报告
python scripts/quality_check.py --input segments.json --output report.json

# 生成 JSON + HTML 报告
python scripts/quality_check.py --input segments.json --output report.json --html

# 带术语表检查
python scripts/quality_check.py --input segments.json --output report.json --glossary data/glossary/k-on_glossary.json

# 运行测试
python scripts/quality_check.py --evaluate
```
