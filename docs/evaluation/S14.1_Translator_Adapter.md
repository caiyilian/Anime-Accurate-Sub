## 实现方案

### 模块 `scripts/translator_adapter.py`

```
TranslatorAdapter (抽象基类)
  +-- SakuraAdapter     (Ollama Sakura-7B/14B)
  +-- QwenAdapter       (Ollama Qwen2.5)
  +-- GalTranslAdapter  (Ollama GalTransl-7B)
  +-- ExternalAdapter   (OpenAI 兼容 API)
```

## 评估结果

### 多后端翻译测试

| 后端 | おはよう、唯 | 今日も元気だね | 澪ちゃん、一緒に練習しない？ |
|:----|:-----------|:-------------|:--------------------------|
| **Sakura-14B** | 早上好，唯 | 今天也很有精神呢 | 小澪，要不要一起练习？ |
| **GalTransl-7B** | "早上好，唯" | "今天也很精神呢" | —小澪，要不要一起练习呢？ |
| Qwen2.5:7b | 404 (本机未安装) | 404 | 404 |

### 后端切换方式

```bash
# 命令行指定后端
python scripts/translator_adapter.py --text "おはよう" --backend sakura
python scripts/translator_adapter.py --text "おはよう" --backend galtransl

# 配置文件切换
python scripts/translator_adapter.py --text "おはよう" --config my_config.json

# 查看可用后端
python scripts/translator_adapter.py --list-backends

# 生成默认配置文件
python scripts/translator_adapter.py --save-config translator_config.json
```
