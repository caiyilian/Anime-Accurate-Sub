# S15.13 Unicode 非语言字幕校验修复

## 问题

全季运行到第 2 集时，Anime Whisper 在片头前识别到 `≪……`，远程 Sakura 返回
`「……`。两者都是用于表现停顿/画外符号的非语言字幕，但原校验依赖手工维护的
字符正则，没有包含数学符号 `≪` 和日文引号 `「`，递归拆分到单条后让整批失败。

此前第 1 集的全角波浪号已经说明逐个枚举 Unicode 标点会持续遗漏。

## 修复

- 用 Unicode 类别判断替换标点白名单：P（标点）、S（符号）、Z（分隔符）均视为
  非语言字符。
- 保留日语语气字幕常见的小促音 `っ/ッ` 和长音 `ー`。
- 只有整个源片段都满足条件时才接受纯标点译文；包含普通假名的 `は?……` 仍然
  必须得到有文字的翻译，防止放宽正常台词校验。

新增测试覆盖第 1 集全角波浪号、第 2 集 `≪…… → 「……` 以及普通假名反例。
