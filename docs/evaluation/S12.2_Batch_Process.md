## 实现方案

### 模块 `scripts/batch_process.py`

| 类 | 功能 |
|:---|:------|
| **BatchProcessor** | 目录遍历 + Pipeline 自动处理 + 模型复用 |
| **BatchStats** | 批量处理统计数据 |

### Pipeline 阶段

```
find_videos → [for each video]:
  extract_audio → asr → translate → subtitle → quality_check
  ↑ checkpoint 自动跳过已完成的阶段
  ↑ 模型缓存复用（ASR/翻译只加载一次）
```

### 核心功能

| 功能 | 说明 |
|:----|:------|
| **目录遍历** | 自动扫描 7 种视频格式（mp4/mkv/avi/mov/wmv/flv/webm） |
| **模型复用** | 通过 `get_or_create_model()` 缓存在内存中，所有视频共享 |
| **断点续传** | 基于 checkpoint 模块，中断后自动跳过已完成视频 |
| **Dry Run** | 预览模式，列出待处理文件但不执行 |
| **视频列表** | `--list` 参数查看目录下的视频文件 |

### 使用方式

```bash
# 批量处理目录下的所有视频
python scripts/batch_process.py --input-dir data/video --output-dir output

# 断点续传（跳过已完成的）
python scripts/batch_process.py --input-dir data/video --output-dir output --resume

# 预览（不实际处理）
python scripts/batch_process.py --input-dir data/video --output-dir output --dry-run

# 查看视频文件列表
python scripts/batch_process.py --list data/video

# 运行测试
python scripts/batch_process.py --evaluate
```
