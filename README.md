# Anime Accurate Sub

> 精准的动漫中文字幕嵌入工具 — 输入日语动漫视频，输出带准确中文字幕的视频。

## 痛点

日语动漫没有中文字幕时，浏览器自动翻译往往错误百出，尤其是动漫中大量的角色名、语气词、专有名词等。本项目旨在通过 **本地 ASR + 本地 LLM 翻译** 的方案，提供真正准确的动漫字幕。

## 核心特性

- 🎯 **准确翻译** — 基于高质量 ASR 识别 + LLM 翻译，而非浏览器级机翻
- 🏠 **本地运行** — 通过 Ollama 支持本地模型，无需联网，数据不出本机
- 🎞️ **动漫优化** — 针对动漫语音场景和语言风格优化
- 📝 **字幕嵌入** — 自动生成并嵌入高质量中文字幕（支持 SRT/ASS）
- 💬 **双语可选** — 支持日语原文 + 中文翻译的双语字幕

## 工作流

```
视频 → 音频提取 → ASR 识别 → LLM 翻译 → 字幕生成
                                              ↓
                                     🤖 多 Agent 审查 ← 5 个 Agent 并行
                                              ↓ 自动修正问题
                                          嵌入视频
```

## 技术栈

| 模块 | 方案 |
|------|------|
| ASR | Whisper / Faster-Whisper / SenseVoice |
| 说话人分离 | pyannote.audio |
| 翻译 | Ollama 本地 LLM（Qwen / Llama 等） |
| 字幕封装 | FFmpeg |
| 语言 | Python |

## 进阶功能路线图

### ✅ 基础管道（首发）
- [ ] 视频音频提取 → ASR 识别 → 日语文本 + 时间戳
- [ ] Ollama 本地 LLM 翻译为中文
- [ ] 生成 SRT/ASS 字幕并嵌入视频

### 🔜 进阶功能
- [ ] **说话人分离** — 识别不同角色，字幕标注谁在说话，角色专属颜色
- [ ] **术语表** — 自定义角色名/招式名翻译，保证一致性
- [ ] **翻译记忆** — 相同台词自动复用已有翻译
- [ ] **OP/ED 自动跳过** — 片头片尾不浪费 ASR 资源
- [ ] **🤖 多 Agent 脚本审查** — 5 个 Agent 并行审查字幕（一致性/逻辑/翻译自然度/ASR纠错/总编），自动发现并修正问题，几乎无需人工介入
- [ ] **双语字幕** — 日文原文 + 中文翻译同时显示
- [ ] **断点续传** — 中断后从中断处继续
- [ ] **批量处理** — 多集自动排队
- [ ] **Web UI** — 图形化操作界面
- [ ] **人工校对** — 交互式翻译修正
