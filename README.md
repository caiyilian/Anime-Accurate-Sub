# Anime Accurate Sub

> 精准的动漫中文字幕嵌入工具 — 输入日语动漫视频，输出带准确中文字幕的视频。

## 痛点

日语动漫没有中文字幕时，浏览器自动翻译往往错误百出，尤其是动漫中大量的角色名、语气词、专有名词等。本项目旨在通过 **本地 ASR + 本地 LLM 翻译** 的方案，提供真正准确的动漫字幕。

## 核心特性

- 🎯 **准确翻译** — 基于高质量 ASR 识别 + LLM 翻译，而非浏览器级机翻
- 🏠 **本地运行** — 通过 Ollama 支持本地模型，无需联网，数据不出本机
- 🎞️ **动漫优化** — 针对动漫语音场景和语言风格优化
- 📝 **字幕嵌入** — 自动生成并嵌入高质量中文字幕（支持 SRT/ASS）
- 💬 **双语可选** — 支持日语原文 + 中文翻译的双语字幕

## 工作流

```
视频 → 音频提取 → ASR 识别 → LLM 翻译 → 字幕生成
                                              ↓
                                     🤖 多 Agent 审查 ← 5 个角色并行 + 总编安全门禁
                                              ↓ 自动修正问题
                                          嵌入视频
```

## 技术栈

| 模块 | 方案 |
|------|------|
| ASR | Whisper / Faster-Whisper / SenseVoice |
| 说话人分离 | pyannote.audio |
| 翻译 | Ollama 本地 LLM（Qwen / Llama 等） |
| 字幕封装 | FFmpeg |
| 语言 | Python |

## 进阶功能路线图

### ✅ 基础管道（首发）
- [ ] 视频音频提取 → ASR 识别 → 日语文本 + 时间戳
- [ ] Ollama 本地 LLM 翻译为中文
- [ ] 生成 SRT/ASS 字幕并嵌入视频

### 🔜 进阶功能
- [ ] **说话人分离** — 角色名映射和专属颜色已完成；动漫场景自动身份识别仍需人工确认
- [ ] **术语表** — 自定义角色名/招式名翻译，保证一致性
- [ ] **翻译记忆** — 相同台词自动复用已有翻译
- [ ] **OP/ED 自动跳过** — 片头片尾不浪费 ASR 资源
- [x] **🤖 多 Agent 脚本审查** — 5 个角色并行审查字幕，SenseNova 多账号轮询，总编仅自动应用高置信度共识；完整结果可审计、可断点续传
- [x] **外挂日文字幕优先** — 单集/整季按集数匹配日文 SRT/ASS，或自动提取内嵌日文文本轨；验证后跳过 ASR，源变化会重建全部下游
- [x] **GEMBA-MQM 质量门禁** — Flash Lite + DeepSeek 双裁判、保守总编和双重复评；只有双方证明候选达到最低分且显著提升才自动应用
- [ ] **双语字幕** — 日文原文 + 中文翻译同时显示
- [ ] **断点续传** — 中断后从中断处继续
- [ ] **批量处理** — 多集自动排队
- [x] **Web UI** — 上传、配置、后台任务、进度日志和结果下载
- [x] **人工校对** — 可审计地导出/导入修正稿，并重新生成字幕
- [x] **插件系统** — 翻译、ASR 和字幕样式插件注册与加载
- [x] **视频预览** — 快速生成指定时间段的准确字幕预览
